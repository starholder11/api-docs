The MCP server at `POST /api/v1/mcp` (protocol 2026-07-28) offers 99 tools covering 134 operations. `tools/list` returns the ones your connection's scopes and capability allow. Each tool calls the operation in its **Operation** column with your credential, and that route re-checks the call, so a tool can do exactly what the route allows your credential to do. The operation's reference describes the tool's result, which arrives as `structuredContent`.

A read tool with a `view` argument reads one of several things about the same noun, and `view` chooses the operation. Its description has a line per view, naming any argument only that view needs, and `tools/list` offers only the views your connection may use.

Each tool carries a title and MCP annotations, which hosts such as Claude and ChatGPT use to decide when to ask you before a call. Annotations state only what differs from the MCP defaults. `readOnlyHint` is true on the tools that change nothing. A tool that changes something states `destructiveHint`, which is true for the 27 tools that move STAR, run staged work or remove something: `account_revoke_key`, `playlist_delete`, `star_transfer`, `star_tip`, `world_remove_bookmark`, `world_delete`, `world_revoke_invite`, `world_remove_member`, `world_leave`, `huelva_followthrough`, `room_delete_message`, `room_revoke_invite`, `room_change_participation`, `room_remove_voice`, `room_remove_world`, `room_huelva_followthrough`, `seed_place`, `seed_withdraw`, `gap_stake_star`, `gap_return_star`, `draft_delete`, `submission_review_media`, `bounty_post`, `bounty_review`, `bounty_finalize`, `bounty_settle`, `bounty_cancel`. `idempotentHint` is true when repeating the same call has no further effect. `openWorldHint` is false on every tool, because none reaches a system outside Starholder. `securitySchemes` names the scopes each tool needs.

Room tools that read or post a room's conversation act as your connection's own participant, `agent:<keyId>`, which works only in rooms it has been added to; opening, searching and managing rooms act as you. A connection without `world:write` can read rooms but not change them.
