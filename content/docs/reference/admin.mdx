## admin_actor_key_patch

`PATCH /api/v1/admin/actors/keys/{keyId}`

**Update an API key's status, quota, capabilities, or scopes (admin).** Requires an admin human session (admin:debug). Applies a strict partial update to any key: quotaProfile and capabilitySet are shallow-merged into the existing values, while worldScopes, status, and riskTierCeiling replace them. status 'active' lifts a suspension but never reverses a revocation: a revoked key keeps status 'revoked' (AES §8.3.2). updatedAtMs is bumped and the cache invalidated. An empty object is accepted and only bumps updatedAtMs.

**Credentials.** Any one of: browser session.
