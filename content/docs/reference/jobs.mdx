## jobs_get

`GET /api/v1/jobs/{jobId}`

**Poll an async execution job.** Resolves the caller with AuthBoundaryDispatcher; personas are rejected. Loads the job from Redis and returns it only when record.actorId equals the caller or the job's ownerUserId equals the caller's owner, so sibling API keys of the same owner, and the owner's session, can read each other's jobs. queued or running jobs return an AsyncJobEnvelope; completed, failed, or expired jobs return an AsyncJobResult containing the ExecutionResult or the error. A job no worker claimed within 60 s of createdAtMs is settled on this read as expired with error.code ERR_JOB_NOT_STARTED (retryable), and a worker can no longer start it; submit the turn again with a new idempotencyKey. Polling only.

**Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session. Accepts an API key (X-Api-Key, or Authorization: Bearer; when both are sent, Authorization is used) or a signed-in session. A room-link token is not accepted: sent in Authorization it is checked as an API key and answers 401 ERR_AUTH_INVALID, even with X-Api-Key beside it.
