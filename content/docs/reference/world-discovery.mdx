## world_discovery_get

`GET /api/v1/world/discovery`

**Search the public world directory.** Searches the public world directory projection (active, public worlds only) by free text with optional owner, tag and publish-mode filters. Each result carries per-caller relationship flags (isBookmarked, isMember, hasPendingInvite) computed at query time for the caller's owning user. Read-only; private worlds are never returned.

**Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session.

**Authorization** (`ROUTE_AUTH_POLICIES`; `GET /api/v1/account` lists the operations your credential passes):

- `world_discovery_get`: callers `human`, `external_agent`; mutation class `none`.
