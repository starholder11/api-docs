## kslp_radio_playlists_post

`POST /api/v1/kslp-radio/playlists`

**Create a KSLP radio playlist (Idempotency-Key required).** Human only. Creates a playlist owned by the caller: the name is NFC-normalized and trimmed, and orderedRefs must be canonical refs. The Idempotency-Key header is required. Replaying the same key with the same request returns the stored playlist with replayed=true, and reusing the key with a different request returns 409. Writes are serialized with a Redis lock (15 s).

**Credentials.** Any one of: browser session. Accepts a signed-in session. An API key answers 403 ERR_AUTH_FORBIDDEN. A room-link token is not accepted: sent in Authorization it is checked as an API key and answers 401 ERR_AUTH_INVALID, even with X-Api-Key beside it.
