## setting_get

`GET /api/v1/world/{worldId}/settings/{ref}`

**Get a world setting's compiled profile.** Resolves a world-scoped setting (place) reference (URL-encoded) to its legacy id and returns the compiled media cross-reference profile: xref identity, media summary, narrative context, and linked entities and settings. References that resolve outside the route world, or do not resolve, return 404. Read-only.

**Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session.

**Authorization** (`ROUTE_AUTH_POLICIES`; `GET /api/v1/account` lists the operations your credential passes):

- `setting_get`: callers `human`, `external_agent`; scopes `world:read`; capability `canRead`; mutation class `none`.
