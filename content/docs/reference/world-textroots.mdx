## textroot_get

`GET /api/v1/world/{worldId}/textroots/{ref}`

**Get the compiled profile of a TextRoot in a world.** Resolves a TextRoot ref within the world and returns its compiled MediaXRef profile (xref identity, media summary, narrative context, linked entities and settings) inside the standard success envelope. Accepts world-scoped `txt:` refs and the legacy `txt:textroot_<textRootId>:story` form; the ref path segment must be URL-encoded because it contains colons. Read-only. Echoes X-Correlation-Id on every response.

**Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session.

**Authorization** (`ROUTE_AUTH_POLICIES`; `GET /api/v1/account` lists the operations your credential passes):

- `textroot_get`: callers `human`, `external_agent`; scopes `world:read`; capability `canRead`; mutation class `none`.
