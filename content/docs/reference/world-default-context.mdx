## world_default_context_get

`GET /api/v1/world/default-context`

**Get the caller's default ('main') world context.** Returns the caller's own default world (the world named 'main' they own) as a management row with relationship, read/publish capability, visibility and lifecycle, plus its worldId and handle. Intended for post-signup and shell bootstrap. Read-only.

**Credentials.** Any one of: browser session.

**Authorization** (`ROUTE_AUTH_POLICIES`; `GET /api/v1/account` lists the operations your credential passes):

- `world_default_context_get`: callers `human`; mutation class `none`.
