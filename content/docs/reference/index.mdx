This reference lists all 146 operations in the Starholder OpenAPI 3.1 document, grouped by tag. It is generated from that document; when the two disagree, the document is right and this page is stale.

The machine-readable document is served at [`GET /api/v1/openapi.json`](https://www.starholder.xyz/api/v1/openapi.json) (`application/vnd.oai.openapi+json;version=3.1`, no authentication). Load it into any OpenAPI client. Each operation carries three Starholder extensions:

- `x-starholder-auth` names the gates the operation enforces: the `ROUTE_AUTH_POLICIES` entries (actor kinds, scopes, capability, risk tier, world policy, ownership, role), or the room-runtime rule for chat routes.
- `x-starholder-sse` lists the server-sent events of a streaming operation.
- `x-starholder-contract` names the route handler the schema was authored from.

This reference describes every operation, whether or not your credential may call it. To see which ones your key may call, request `GET /api/v1/account` with the key and read `data.directory`; the [Discovery](/docs/discovery) page explains the chain. A `routeId` in that directory is an `operationId` here, or one of the policies of a merged operation.
