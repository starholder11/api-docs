## entity_list

`GET /api/v1/world/{worldId}/entities`

**List a world's featured entities ranked by narrative reach.** Returns the world's entities ranked by narrative reach: distinct stories containing the entity, then multi-scene story count, scene count, latest supporting story recency, and name. The result includes total, the count of all eligible entities. Only the top N are returned; there is no cursor.

**Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session.

## entity_get
