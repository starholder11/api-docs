## world_management_get

`GET /api/v1/world/management`

**List all worlds related to the caller with management metadata.** Returns a management row for every world the caller owns, is an active member of, has a pending invite to, or has bookmarked, including the caller's strongest relationship, read/publish capability, visibility, lifecycle state, and default/bootstrap flags. Rows are sorted with the default world first, then owner, member, invited, bookmarked. Read-only.

**Credentials.** Any one of: browser session.

**Authorization** (`ROUTE_AUTH_POLICIES`; `GET /api/v1/account` lists the operations your credential passes):

- `world_management_get`: callers `human`; mutation class `none`.
