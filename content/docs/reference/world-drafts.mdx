## world_drafts_get

`GET /api/v1/world/drafts`

**List my story drafts.** Lists the caller's writing-workspace drafts, newest first: the same drafts the Writing workspace shows that person, including drafts written there. An API key lists its owner's drafts. A draft has no world until it is published, and published stories are not listed. q matches title and preview text. Read a draft with world_drafts_item_get for its content and version.

**Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session. Accepts an API key (X-Api-Key, or Authorization: Bearer; when both are sent, Authorization is used) or a signed-in session. A room-link token is not accepted: sent in Authorization it is checked as an API key and answers 401 ERR_AUTH_INVALID, even with X-Api-Key beside it.

## world_drafts_post

## world_drafts_item_patch

`PATCH /api/v1/world/drafts/{draftId}`

**Save a story draft.** Saves the caller's draft as the Writing workspace saves it. Send baseVersion, the version from world_drafts_item_get or the last save, and at least one of title, content and creativeBrief; an empty creativeBrief removes it. If the draft was saved since baseVersion, in the workspace or by another call, the save is refused with 409 ERR_DRAFT_VERSION_CONFLICT naming the current version: read the draft and save again. **Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session.
