## world_bookmarks_post

## world_bookmarks_delete

`DELETE /api/v1/world/bookmarks`

**Remove a world bookmark.** Removes one of the caller's bookmarks by bookmarkId, deleting the stored bookmark JSON, the Postgres mirror row, and the graph edge. The bookmarkId is sent in a JSON request body on the DELETE. Not idempotent: a second call returns 404.

**Credentials.** Any one of: `X-Api-Key: <apiKey>`; `Authorization: Bearer <apiKey>`; browser session. Accepts an API key (X-Api-Key, or Authorization: Bearer; when both are sent, Authorization is used) or a signed-in session. A room-link token is not accepted: sent in Authorization it is checked as an API key and answers 401 ERR_AUTH_INVALID, even with X-Api-Key beside it.

For every request, the first request changes nothing and answers `428` with what it would remove; resending the identical request with `X-Starholder-Confirmation: <confirmationId>` within 5 minutes runs it once.
