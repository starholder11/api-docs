## world_bookmarks_get

`GET /api/v1/world/bookmarks`

**List the caller's world bookmarks.** Returns all of the caller's world bookmarks, newest first, from the Postgres bookmark mirror. A bookmark is only a pointer and confers no access to the world. Read-only.

## world_bookmarks_post

`POST /api/v1/world/bookmarks`

**Bookmark a world.** Adds a bookmark for a world the caller can currently read or has a pending invite to. Writes the canonical bookmark JSON to storage, mirrors it in Postgres, and upserts a rebuildable graph edge. Idempotent: if the caller already bookmarked the world, returns 200 with the existing bookmarkId and code already_bookmarked.

**Credentials.** Any one of: browser session. Accepts a signed-in session. An API key answers 403 ERR_AUTH_FORBIDDEN. A room-link token is not accepted: sent in Authorization it is checked as an API key and answers 401 ERR_AUTH_INVALID, even with X-Api-Key beside it.

## world_bookmarks_delete
