## world_memberships_get

`GET /api/v1/world/memberships`

**List world memberships (a world's collaborators or your own).** With worldId, returns the active collaborators of that world (oldest first) and requires the caller to own it. Without worldId, returns all of the caller's own memberships in every status (active, revoked, left), newest first. Each row includes username and displayName. Read-only.

**Credentials.** Any one of: browser session. Accepts a signed-in session. An API key answers 403 ERR_AUTH_FORBIDDEN. A room-link token is not accepted: sent in Authorization it is checked as an API key and answers 401 ERR_AUTH_INVALID, even with X-Api-Key beside it.

**Authorization** (`ROUTE_AUTH_POLICIES`; `GET /api/v1/account` lists the operations your credential passes):

- `world_memberships_get`: callers `human`; mutation class `none`.

## world_membership_leave_post
